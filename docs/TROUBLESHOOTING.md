# 故障排查

## 面板没有数据

1. 在浏览器中直接打开 `https://status.input.im/api/status`，确认网络可访问且返回 JSON。
2. 打开扩展面板并点击右上角刷新按钮。
3. 进入设置页，确认模型优先级中的名称与接口中的 `services[].model` 完全一致。
4. 在扩展管理页重新加载扩展，再次打开面板。

## 没有收到桌面通知

依次检查：

1. 扩展设置中的“桌面通知”是否开启。
2. 浏览器是否被操作系统允许发送通知。
3. Windows 的“请勿打扰”或 macOS 的“专注模式”是否拦截通知。
4. 浏览器是否仍在运行。浏览器完全退出后，扩展无法继续轮询。

扩展只在状态发生变化时通知。首次安装、浏览器启动和修改设置后的初始化刷新不会补发历史通知。

## 状态接口读取失败

默认权限只允许访问 `https://status.input.im/*`。即使设置页可以编辑接口地址，改成其他域名后也会因浏览器权限限制而失败。若需要支持其他数据源，必须同步修改 `manifest.json` 中的 `host_permissions`，然后重新加载扩展。

接口失败不会停止监控任务。扩展会保留最近一次成功数据，并按检查间隔继续请求；接口恢复后会自动处理返回的未读状态样本。浏览器完全退出或系统休眠期间无法执行轮询，恢复后的统计准确度取决于接口保留的历史样本范围。

## 自动选择的模型不符合预期

模型优先级从上到下生效。插件优先选择列表中第一个当前正常的模型；如果列表内全部异常，会继续跟踪列表中最高优先级且仍存在的模型。请检查模型名称拼写和排序，保存设置后插件会立即重新选择一次。

## 今日统计与状态站不同

今日统计是扩展根据已经获取的样本在本地累计的结果，不是服务端完整历史数据。以下情况会造成差异：

- 扩展刚刚安装
- 浏览器曾完全退出或设备休眠
- 浏览器推迟了后台任务
- 扩展数据被清除或扩展被重装
- 状态接口返回的历史样本不足以覆盖全天

## 查看后台错误

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 找到 AI.INPUT.IM Status Monitor。
3. 点击“Service Worker”旁边的检查链接。
4. 在开发者工具 Console 中查看请求或脚本错误。

反馈问题时，请附上浏览器版本、操作系统、扩展版本、模型优先级、当前选中模型和 Console 中的错误信息。不要提交任何账号凭据或浏览器个人数据。
